# Finance Policy v1.3.0 — Gateway Settlement Accounting

**Effective:** 2026-10-08  
**Source reference:** `FIN-Phase-2E-GATEWAY-SETTLEMENT-ACCOUNTING`

## Customer charge

The HealthApp platform service fee is currently **5.00%** and includes gateway processing economics. There is no separate customer-facing gateway charge.

## Actual gateway cost

The actual provider gateway fee is an internal accounting cost and must be recorded from provider settlement/reconciliation evidence. The payment-status API's customer payment amount is not treated as gateway-cost evidence.

For a reconciled payment:

`Net settlement = Gross payment - Gateway fee - Gateway-fee tax + Other provider adjustment`

All values are stored in INR with two-decimal precision. Negative gateway fees/taxes are rejected.

## Double-charge prevention

A gateway fee must not be added to the customer's invoice/payment amount after the 5% platform service fee has already been calculated. Gateway settlement deductions affect platform economics/accounting only.

## Reconciliation controls

Each payment transaction can have at most one gateway settlement record. The record stores provider payment ID, settlement ID, gross amount, actual gateway deductions, net settlement, source evidence, reconciliation reference and reconciler identity.

Historical payment and finance records remain immutable; later gateway reconciliation does not rewrite the original customer calculation.
