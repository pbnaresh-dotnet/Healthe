# Finance Policy v1.2.9 — Onboarding Setup Fee Governance

**Effective:** 2026-10-08  
**Source reference:** `FIN-Phase-2D-ONBOARDING-SETUP-FEE-GOVERNANCE`

The outlet onboarding setup fee is a **platform-level commercial charge**, separate from customer meal/package revenue and outlet transaction-fee calculations.

The amount is read from `Onboarding:SetupFee` and defaults to **₹5,000.00** when no configuration override is supplied. The value is validated and rounded to two decimal places before a payment transaction is created.

The configured amount is persisted on the onboarding application and outlet SaaS subscription so the historical amount charged remains reproducible even if the platform configuration changes later.

Future changes to this financial rule require a new finance-policy version and source-code reference.
