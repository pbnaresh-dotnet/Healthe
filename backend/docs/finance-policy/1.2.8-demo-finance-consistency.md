# Finance Policy v1.2.8 — Demo Finance Consistency

**Effective:** 2026-10-08  
**Source reference:** `FIN-Phase-2D-DEMO-FINANCE-CONSISTENCY`

Demo financial fixtures must use the same active commercial economics as production. The demo subscription fixture has therefore been aligned with the 5.00% HealthApp platform service fee, including the corresponding platform service tax and customer payable amount.

Demo data is illustrative, but it must remain arithmetically consistent with production calculations so outlet users, testers and auditors do not learn obsolete financial rules from the demo.

This change does not modify historical production finance snapshots.
