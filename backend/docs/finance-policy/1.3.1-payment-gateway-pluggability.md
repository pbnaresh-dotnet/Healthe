# Finance Policy v1.3.1 — Payment Gateway Pluggability

**Effective:** 2026-10-08  
**Source reference:** `FIN-Phase-2E-PAYMENT-GATEWAY-PLUGGABILITY`

Payment processing is provider-neutral. Customer pricing, tax, commission, discount, settlement and finance snapshot calculations must not depend on Cashfree, Razorpay, Stripe or another gateway.

Each provider implements the `IPaymentGatewayAdapter` contract for provider-specific checkout creation, payment-status retrieval, webhook parsing and signature validation. The application selects the configured adapter through `IPaymentGatewayFactory`.

Changing providers must not rewrite historical `PaymentTransaction`, `FinanceCalculationSnapshot`, financial-document or settlement records. Provider migration is therefore an infrastructure/adaptor change rather than a change to the commercial calculation rules.

Webhook routes and signature formats are provider-neutral at the application boundary; provider-specific header and payload interpretation remains inside the adapter.
